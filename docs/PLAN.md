# 好食光 MealWise — 規劃書

> 兼具享受美食與智慧管理的生活態度

## 1. 核心理念

**「計畫先做好，記錄只要點一下」**
大部分的輸入在「規劃菜單」時就完成了，吃飯當下只需要確認。

## 2. 功能地圖

| 模組 | 做什麼 |
|---|---|
| 🙋 我的需求 | 目標（減脂／增肌／維持）、熱量與飲水目標、過敏、不吃的東西、素食等 |
| 📖 食譜庫 | 依需求自動過濾；可收藏、可自建；每道菜附份量與營養 |
| 📅 一週菜單 | 拖拉食譜到早／午／晚／點心；可「一鍵幫我排」 |
| 🛒 採購清單 | 從菜單自動算出食材、合併同類（2 道菜都用洋蔥 → 合成一筆）、依賣場區域分類、勾選打勾 |
| 🔪 備料清單 | 週末備餐用：哪些先洗、先切、先煮、可冷凍幾天 |
| ✅ 每日記錄 | 餐點、飲水、營養素 |
| 📊 營養統計 | 今日圓環、一週趨勢、哪些營養素常不夠 |

## 3. 減少輸入壓力的設計

1. **照計畫吃 → 點一下 ✓**：今天的菜單直接顯示，吃了就打勾。
2. **沒照計畫？三種快速替代**：
   - 「最近吃過」一鍵重複
   - 「常吃組合」（例：早餐固定組）
   - 拍照先存，有空再補（之後可加 AI 辨識）
3. **份量不用秤**：用「小／中／大」或「半碗／一碗」，不強迫輸入公克。
4. **飲水大按鈕**：點一下 +250ml，長按可改量。
5. **允許「大概」**：記錄不完美也沒關係，比不記好。
6. **溫和提醒**：可選的用餐／喝水提醒，不轟炸。

## 4. 動畫與互動回饋

原則：**快、柔、有意義**（每個動畫都在告訴使用者「發生了什麼」）

| 情境 | 效果 |
|---|---|
| 換頁 | 左右滑入（同層）、由下往上（開新視窗），約 250ms |
| 點食譜卡 → 詳細頁 | 卡片圖片「放大延伸」成詳細頁（共享元素轉場） |
| 打勾完成 | 勾勾彈一下 + 手機輕震 |
| 喝水 | 水杯水位上升的波浪動畫 |
| 營養圓環 | 數值變化時圓環平滑填滿 |
| 刪除 | 滑開刪除 + 「復原」提示條 |
| 按鈕 | 按下微微縮小，放開回彈 |
| 載入中 | 骨架畫面（灰色佔位），不用轉圈圈 |

另外：尊重手機「減少動態效果」設定，自動降低動畫。

## 5. 技術選擇（白話版）

| 用途 | 選擇 | 為什麼 |
|---|---|---|
| 畫面框架 | React + TypeScript + Vite | 主流、好找資源、開發快 |
| 變成可安裝 App | vite-plugin-pwa | 可加到主畫面、離線可用 |
| 資料存放 | IndexedDB（用 Dexie） | 存在手機裡，沒網路也能用 |
| 動畫 | Framer Motion | 彈性動畫、換頁、共享元素轉場都好做 |
| 樣式 | Tailwind CSS | 快速做出一致的設計 |
| 營養資料 | 衛福部「台灣食品營養成分資料庫」 | 公開、在地食材齊全 |

## 6. 畫面結構（底部 4 個分頁）

```
[ 今天 ]  [ 菜單 ]  [ 清單 ]  [ 我的 ]
  │         │         │         └ 需求設定、統計、食譜收藏
  │         │         └ 採購清單 / 備料清單 切換
  │         └ 一週菜單、食譜庫
  └ 今日三餐打勾、飲水、營養圓環
```

## 7. 開發階段

**第一階段（MVP，先能用）**
- 需求設定（首次引導 3 步驟）
- 內建 30–50 道食譜
- 一週菜單 + 自動採購清單
- 今日打勾記錄 + 飲水
- 基本動畫與 PWA 安裝

**第二階段（變聰明）**
- 營養統計與趨勢
- 備料清單
- 一鍵自動排菜單（依需求與營養平衡）
- 冰箱剩餘食材 → 推薦食譜

**第三階段（變方便）**
- 雲端同步、多裝置
- 家人共用採購清單
- 拍照 AI 辨識餐點
- 匯入網路食譜
